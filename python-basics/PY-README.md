# Password Strength Checker

A beginner Python project that checks password strength based on several criteria.

## What It Checks

- Password length
- Numbers
- Uppercase letters
- Lowercase letters
- Special characters

## What I Learned

- Python functions
- Conditional statements
- Loops and `any()`
- String handling
- Basic password-security concepts

## Disclaimer

This project is for educational purposes and should not be used as a professional password-security tool.
